## Reporting a vulnerability

Email **security@creditchain.org**. Please do not open a public issue for a security problem.
The machine-readable contact is at `https://www.creditchain.org/.well-known/security.txt`.

## Audit status

CreditChain has not yet completed an external security audit. Test CCC has no value, and the
network should be treated accordingly until an audit is published here.
